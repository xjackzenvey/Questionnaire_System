# 问序视觉系统

当前主屏参考：`editor-concept-light.png`，1536 × 1024。原始深绿色参考保留为 `editor-concept.png`。

- 参考钉钉的浅色办公界面：浅灰侧栏 #f7f8fa、白色文档和讨论栏、冷灰背景 #f5f6f8；主色 #1677ff、选中背景 #e6f0ff、边框 #e7eaf0。
- 使用系统中文无衬线字体，优先苹方、微软雅黑，去除远程 Google 字体请求；文档标题 28–32px，桌面题目 16px，正文与批注 14px，辅助信息至少 12px，避免过细字体和过重字重。
- 左侧全局导航 + 顶部工具栏 + 标签栏 + 问卷大纲 / 文档 / 批注三栏。
- 圆角 6–8px，细边框，避免装饰图片和渐变。
- 按钮、输入、问题卡、讨论串、弹窗统一组件和状态。
- 移动端收起大纲，批注通过工具栏按钮切换；保留所有主要操作。

有意调整：参考图多出的问卷模板、团队协作、账号设置、附件上传和 @ 提及不属于第一版需求，予以移除。保存使用显式手动保存；显示真实保存状态。题型、必填、题目移动与删除控件是编辑器必需功能。其余页面沿用相同颜色、文字和组件系统。
